# Lemonade Stand：可玩的 2D 小游戏方案

调研日期：2026-10-02。此文是改造方案，本轮尚未修改线上游戏。

## 游戏方向

俯视角像素风街边经营游戏。场景占据主要画面：木制柠檬水摊、店主、人行道、树木和移动顾客。顶栏只显示天数、资金、库存、营业剩余时间；采购和定价在开店前的短面板中完成。

玩家的操作要影响结果：点击摊位或按空格开始制作，短暂制作完成后递给队首顾客。每次完成交易才扣除原料并增加收入；制作失败、价格拒绝、耐心耗尽均不能产生收入。动作有饮料、硬币、表情和音效反馈。

## 一天怎么玩

1. 开店前购买原料、设置配方和售价，保留现有经营逻辑中合理的部分。
2. 营业约 60–90 秒，顾客以随机间隔从街道入口走进场景。
3. 顾客决定路过、购买或因价格离开；愿意购买的人走到队尾。
4. 队首显示饮料订单和耐心条。玩家制作、递出饮料，资金和原料立即更新。
5. 耐心耗尽、队伍满、售价过高或售罄会让顾客离开；不同情况使用不同表情反馈。
6. 到时间后停止新顾客入场，处理剩余队列后结算，再进入下一天。

第一版以营业和制作节奏为核心，不同时引入自由移动店主、复杂配料拖拽、装修系统等额外操作。

## 顾客移动与排队

顾客流程：入场 → 走向摊位 → 排队 → 下单 → 等待制作 → 付款取货 → 离场。

拒绝购买或等待超时可从相应状态转入离场。每个顾客只能成交一次，交易完成后立即释放队列位置。

- 使用固定入口、路点、3–4 个排队位置和出口。第一版地图没有动态障碍，不需要复杂寻路。
- 每帧按速度和经过时间推进位置；按移动方向切换行走帧，停下切换待机帧。
- 每个队列位置只允许一个顾客占用；前面的顾客离开后，后面的人走到新的目标点。
- 按角色脚底的纵坐标排序绘制，保证人物经过摊位和其他角色时遮挡自然。
- 暂停时停止营业计时、耐心和生成；窗口恢复后不瞬间补算整段离开时间。
- 触屏提供同一制作按钮；电脑支持点击和空格。制作中锁定重复操作。

## 技术结构与实施顺序

独立站建议使用 TypeScript + Phaser + Vite；门户继续使用 Next.js。Phaser 的场景、精灵动画和输入能力符合本方案，具体稳定版本在实施时确认：[官方学习入口](https://phaser.io/learn)。

保留整数分表示金额的纯经营模块，但替换当前一次性 runDay 的流程为单个顾客的逐笔交易。经营规则不能依赖精灵坐标，动画也不能自己决定资金。

建议分为场景、顾客状态、队列、交易、库存、营业时钟和界面模块。先交付一条完整可玩的流程，再补内容：

1. 像素场景 + 一位顾客走来 + 玩家制作 + 顾客付款离开。
2. 多顾客排队 + 耐心 + 价格拒绝 + 售罄 + 一天倒计时。
3. 开店前采购和定价 + 日终利润 + 下一天 + 手机输入。
4. 补充动画、音效和本地存档，更新门户 Preview 为实际游戏截图。

验收重点：可以连续玩完整一天；操作改变成交数；角色不会占用同一个队列位置；库存不为负、顾客不重复付款；钱和画面同步；下一天可继续；鼠标、键盘和触屏均可玩。经营与队列规则使用针对性测试，场景行为在浏览器实际试玩。
